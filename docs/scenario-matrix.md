# Scenario matrix

Source: the Captain's Basic Set scenario section (SG, SH and SM scenarios) plus the Master Rulebook's scenario rules (S1 to S8). Status: **Built** = playable in the game now, **Planned** = the rules and ships needed are in the supplied books and it is on the build list, **Blocked** = something it needs is not in the supplied books.
Every scenario also offers the same extras: a year (Y168 by default) that decides which ships and refits exist, Commander's Option Items (S3.2, up to 20% of BPV), drone speed choices, and refits by agreement. None of those extras is built yet (see the last section).
