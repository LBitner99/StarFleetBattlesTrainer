"Text not supplied" means the rules live in a module or book that is not in the files supplied (Module J, Module R10, Module B and similar), so they cannot be built without guessing.

## Bugs

- **Post-game strategy analysis (reported 2026-11-21; fixed in v183 and v184, audit still open).** The debrief advised HET (and high energy turns, sideslip, overloads) in a Basic Set game where those rules were off. v183 gated those pieces of advice; v184 writes the rules in force (preset, every option on and off) as the oldest line of the game log when the game starts, and the debrief reads them back from that log line (`rulesLine`, `ruleOn` in `js/33-debrief.js`), so changing options afterwards cannot change the advice. Still to do: audit every other debrief suggestion against the rules in force (so far only HET, sideslip, high energy turns and overloads are gated; the others were read and use Basic Set features only), and add the Master Rulebook and scenario options (landing, zones, cloak, legendary officers and so on) to the logged list.

- **Romulan ship selector: fixed in v177.** The Romulan, Kzinti and Tholian race lists held the Q-ships of the race they borrow from (R1.7A), so clicking one switched the tab to Gorn, Klingon or Federation. Q-ships are now listed only under the Federation, Klingon and Gorn. The SG4 convoy Q-ship option still gives a Romulan, Kzinti or Tholian game the borrowed Q-ship (R1.7A), because it picks it by race, not from the list.

## SH5 (v196): what was not built
- You can only fly the Klingon F5; the Kzinti side is always the computer. The computer carrier launches fighters as in the other scenarios (once the F5 is within 16 hexes) and does not use the admin shuttles as fighters (SH5.8 tactics hint) or the second player options.
